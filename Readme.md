Task Manager App
A simple full-stack Task Manager application where users can create, view, and delete tasks after logging in.

-Tech Stack

-Frontend
1. React
2. Tailwind CSS
3. Redux Toolkit
4. React Router DOM


-Backend
1. Node.js
2. Express.js
3. MongoDB
4. JWT Authentication


-Features
1. User Signup & Login
2. Protected Dashboard
3. Create and Delete Tasks
4. JWT Authentication
5. Responsive UI


How to Start the Project
1. Clone the Repository
git clone <your-github-repo-url>
cd task-manager

2. Start Backend
cd backend
npm install
node app.js
or if using nodemon
nodemon app.js

Backend runs on:
http://localhost:5000

3. Start Frontend
cd frontend
npm install
npm run dev

Frontend runs on:
http://localhost:5173
